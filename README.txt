QuickType — Standard React.js Project (No Vite)
=================================================

To run this React project in your terminal:

1. Open PowerShell or Command Prompt.
2. Navigate to this folder:
   cd C:\Users\parve\Downloads\quicktype-react

3. Install the React packages:
   npm install

4. Start the React app:
   npm start

The app will compile and automatically open in your browser at:
http://localhost:3000
